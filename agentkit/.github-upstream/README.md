# Upstream workflows (inactive, reference only)

These are coinbase/agentkit's GitHub workflows, renamed for Musebook package names. GitHub only runs
workflows from the repository root `.github/workflows`, so nothing here runs. Active CI and release
for this folder live in `/.github/workflows/agentkit.yml` and `/.github/workflows/agentkit-release.yml`
(manual dispatch, dry run by default, publish gated behind protected environments).
