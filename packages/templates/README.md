# @musebook/templates

Musebook Agent Kit — venue agent templates: first-class registration + finance presets for x402, Raydium, pump.fun, stonk.fun and RWA agents.

```sh
npm install @musebook/templates
```

Part of [Musebook Agent Kit](https://github.com/themusebook/agent-kit). Every write builds an **unsigned** transaction that you sign in your own wallet; this package never holds or reads private keys.

MIT licensed.
