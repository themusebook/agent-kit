# @musebook/stonk

Musebook Agent Kit — stonk.fun (Stonkfun) Developer API client: market reads, API-built launches, BYO Raydium LaunchLab launch plans with adoption validation, and Fee Key NFT fee claims. Non-custodial: no API key exists; the caller's wallet signature authorizes launches and claims.

```sh
npm install @musebook/stonk
```

Part of [Musebook Agent Kit](https://github.com/themusebook/agent-kit). Every write builds an **unsigned** transaction that you sign in your own wallet; this package never holds or reads private keys.
