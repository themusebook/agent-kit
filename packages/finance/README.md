# @musebook/finance

Musebook Agent Kit — agent token finance: Genesis launch builders (createAndRegisterLaunch) and the permanent setAgentTokenV1 binding, as caller-signed payloads only.

```sh
npm install @musebook/finance
```

Part of [Musebook Agent Kit](https://github.com/themusebook/agent-kit). Every write builds an **unsigned** transaction that you sign in your own wallet; this package never holds or reads private keys.
